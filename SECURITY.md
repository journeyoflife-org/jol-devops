# Security Policy

## Supported Versions

| Version | Supported          |
|---------|--------------------|
| `main`  | :white_check_mark: |

## Reporting a Vulnerability

**Do NOT open a public issue for security vulnerabilities.**

1. Email: **security@journeyoflife.org**
2. Include: description, affected component, reproduction steps.
3. Expect acknowledgment within **48 hours**.
4. We will coordinate disclosure timeline with you.

## Scope

This policy covers:
- All repositories under `journeyoflife-org`
- GitHub Actions workflows
- Kubernetes manifests and Helm charts
- Infrastructure-as-Code in this repository

## Bug Bounty

JOL does not currently operate a bug-bounty programme.  
Responsible disclosures are acknowledged in our CHANGELOG.
